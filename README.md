### Contenido de este Repositorio:
* `index.html`: Plataforma web interactiva con calculadoras geométricas de interés compuesto, evaluador de activos bursátiles (FIBRAs y ETFs) y simulador de escenarios de estrés.
* `video_explicativo_adultos.mp4`: Video pedagógico Full HD 1080p para adultos.
* `video_explicativo_ninos.mp4`: Video pedagógico Full HD 1080p para niños y jóvenes.
* `GUIA_PASO_A_PASO_COMPRA_BITSO_Y_ACTINVER.pdf`: Guía operativa para apertura de cuentas y órdenes Límite (Maker).
* `FICHA_INFOGRAFICA_BITCOIN_PARA_TODOS.pdf`: Infografía sobre emisión finita y reserva de valor.
* `MANUAL_DE_PRIMERA_VEZ_POR_EDADES.pdf`: Manual formativo por etapas de vida.
* `TALLER_FINANZAS_PREPA_ADULTOS_CTE_PADRES.pdf`: Taller para padres y educadores.
